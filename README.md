# Ecommerce Hub

## Overview
This project is an Ecommerce Website built using HTML, CSS, and JavaScript. The website provides a basic framework for an online shopping experience, including product browsing, adding items to the cart, and interacting with a simple cart system. This project seeks to demonstrate my front-end development skills with a focus on creating responsive layouts and interactive elements.

## Features

- **Product Catalog**: Display of available products with basic information like title, description, price, and images.
- **Shopping Cart**: Users can add products to their cart, view the cart contents, and calculate the total price.
- **Product Details Page**: Clicking on a product title redirects the user to a page with more detailed information.
- **Responsive Design**: The layout adjusts to different screen sizes, making it accessible on both desktop and mobile devices.
- **Add To Cart**: Displays a user interface to allow users to add a product to  cart, although no actual payment system is integrated in this version.

## Technologies Used

- **HTML**: Structure of the web pages, including the product listing, cart, and checkout pages.
- **CSS**: Styling for layout, fonts, colors, buttons, and responsive design.
- **JavaScript**: Interactivity, including adding/removing items from the cart, calculating total prices, and managing cart state.

## Installation

To run the website locally, follow these steps:

1. Clone the repository:

    ```bash
    git clone https://github.com/AdikaNathaniel/ecommerce_site.git
    ```

2. Open the project folder in your preferred text editor (e.g., VSCode).

3. Open the `index.html` file in your browser to view the website.

## How The App Works
To navigate through the website, start by exploring the home page, where you can view a list of available products.
Use the search bar at the top to filter products based on specific keywords, making it easier to find what you're looking for.
If you want to add a product to your shopping cart, simply click the "Add to Cart" button located on the product page.
This button has a hover effect that turns it orange, signaling that it is ready to be clicked. 
To view the contents of your cart, click the cart icon at the top-right of the page.
If you wish to log in to your account, click the login button (please note that backend authentication is not implemented in this version). 
Additionally, you can use the navbar links to easily navigate between different pages, such as the home page, cart, and product detail pages.

## User Interface
The user interface of this eCommerce website is designed with a focus on simplicity and usability:
- **Clean Layout**: The website is organized into clear sections, making it easy for users to find what they need. The product catalog is presented in a grid format, and the cart icon is always visible in the top-right corner for quick access.
- **Hover Effects**: Interactive elements like the "Add to Cart" button change color when hovered over, providing immediate visual feedback to users and making the site feel responsive and dynamic.
- **Responsive Design**: The layout adjusts to different screen sizes, ensuring that the website looks great on all devices. Whether you're browsing on a desktop, tablet, or smartphone, the design remains functional and aesthetically pleasing.
- **Easy Navigation**: The top navigation bar allows users to quickly jump to different sections of the site, such as the product catalog, login page, or shopping cart. The navigation is intuitive, ensuring a smooth user experience throughout the site.
